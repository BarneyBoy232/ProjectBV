# Scope

**This app is:** a fleet remote-management console for one operator.
**It lets** a single operator deploy apps and files to, and remotely see, control,
monitor and browse the files of, a small set of Windows devices they own or manage
with consent — and delegate that control to an AI the operator authorises with an
API key (the Agent API tool), which can run administrative actions only on devices
the operator has explicitly armed.
**It does not:** manage devices without the owner's consent, act as a public
multi-tenant product, or sell anything.
